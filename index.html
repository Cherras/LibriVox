Ayuda y privacidad

La búsqueda pasa por una función de Cloudflare Pages que consulta la API pública de LibriVox. Tus favoritos, notas y estados no se envían al intermediario; se guardan en el almacenamiento local del navegador. No existe sincronización automática entre dispositivos.

Para publicar: sube este proyecto a un repositorio GitHub y conéctalo a Cloudflare Pages. Las funciones no funcionan al abrir el HTML desde Descargas. Para usarlo como aplicación, visita la URL HTTPS publicada.
